# Steam Deck Universal Hotspot Tool

A self-contained solution to provision and toggle a persistent Wi-Fi access point profile on SteamOS, ensuring full visibility across both the command-line (`nmcli`) and desktop GUI network managers.

## Setup Instructions

1. Clone or copy the repository files to your Steam Deck.
2. Run the installer script to generate the system configuration and install the toggle binary:
   ```bash
   ./install.sh
